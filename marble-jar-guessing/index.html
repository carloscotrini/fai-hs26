Open the shared sheet
  1. Open the shared sheet and scroll to row --. It is the row Google Sheets numbers -- in the grey margin, and column A says so too.
  2. Type ---- in the code column.
  3. Type your guess, a whole number, in the guess column.

If that row already holds a different code, take the next empty row down, and carry on from row 6 after row 105. Write your code there.

Come back any time: the same two numbers always give you the same row and the same code, so you change your own guess instead of adding a second one.

What this does with your two numbers

It mixes them into one number and reads a row and four letters off it, here on your phone. Nothing is sent anywhere, this page has no network connection of its own, and the sheet only ever holds a four letter code and a number of marbles. Many birthdays lead to the same row, so a row says nothing about who you are.
